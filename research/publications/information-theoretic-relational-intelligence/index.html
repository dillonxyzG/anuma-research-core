ANUMA RESEARCH ARCHIVE · PUBLICATION 005

Information-Theoretic Foundations of Relational Intelligence

A formal investigation of whether relational structure, memory and context contain predictive information about future system states.

Research ID: ANUMA-ITRI-005 Proposed Framework Information Theory

Abstract

This document develops an information-theoretic formulation of the Transactional–Relational Intelligence framework.

The central question is whether relational variables contain information about future system states that cannot be explained by the system's current state alone.

The framework therefore proposes a measurable distinction between a system that processes immediate transactions and a system whose predictions and transformations depend upon relationships, memory and contextual structure.

Scientific status

The equations in this document constitute proposed mathematical models and testable hypotheses. They should not be interpreted as established empirical laws until supported by experimental evidence.

1. The Information Problem

A conventional transactional description of a system often concentrates on the current state and the immediate input-output relationship.

Let the current system state be represented by:

Xt

A transactional model can therefore be expressed conceptually as:

Xt+1 = F(Xt, Ut)

where Ut represents an immediate input, operation or transaction.

The relational framework introduces additional variables representing the structure surrounding the current state:

St = (Xt, Rt, Mt, Ct, At)

where:

  • X = system state
  • R = relational structure
  • M = memory
  • C = context
  • A = agency

2. Transactional Information

Let Xt+1 denote the future state of a system. The information available in the present state about that future can be represented using mutual information:

I(Xt+1; Xt)

This quantity describes the statistical dependence between the current and future states.

A transactional model may therefore attempt to predict future behaviour primarily from immediate state variables and inputs.

3. Relational Information

The central proposition of the relational framework is that the relationship between entities may contain information that is not reducible to an individual state variable.

Let Rt represent relational structure. The corresponding information relationship can be represented as:

I(Xt+1; Rt)

However, the stronger question is whether relational information remains predictive after the current state has already been taken into account.

I(Xt+1; Rt | Xt)

This conditional mutual information becomes a central proposed measurement for the framework.

4. The Core Test

I(Xt+1; Rt | Xt) > 0

If this quantity is empirically greater than zero under an appropriate experimental design, then relational structure contains predictive information about the future state beyond the information contained in the current state alone.

This does not by itself establish causation. It establishes a statistical relationship that can motivate further investigation.

5. Relational Information with Memory

Relationships may persist through time. The system therefore includes memory:

Mt

The proposed extended information quantity becomes:

I(Xt+1; Rt, Mt | Xt)

This formulation asks whether relationships and accumulated history jointly provide information about the future state beyond the present state.

6. Contextual Information

Context provides another layer of structure. Let Ct represent environmental, social, spatial or situational context.

I(Xt+1; Rt, Mt, Ct | Xt)

The expression represents a proposed test of whether relational, historical and contextual information jointly contribute to prediction.

7. Conditional Independence as a Baseline

A purely transactional hypothesis can be expressed as the conditional independence assumption:

Xt+1 ⟂ (Rt, Mt, Ct) | Xt

If this assumption holds, then once Xt is known, the additional relational variables provide no further predictive information.

The relational framework instead investigates circumstances under which this conditional independence does not hold.

8. Information and Intelligence

The framework distinguishes information from intelligence.

Information represents available structure or statistical dependence. Intelligence concerns the ability of a system to use such information in prediction, adaptation, coordination or transformation.

Proposed distinction

Information describes what structure is available. Intelligence concerns how a system incorporates that structure into adaptive behaviour.

9. Relational Intelligence

The broader relational intelligence formulation is represented as:

IR = f(R, M, C)

This formulation treats relational intelligence as dependent upon relationships, memory and context rather than immediate transactions alone.

The model remains a proposed abstraction whose measurable form must be determined through experimental work.

10. Transactional–Relational Intelligence

A combined model proposed in the broader framework is:

I = IT + λIR

where:

  • IT represents transactional intelligence
  • IR represents relational intelligence
  • λ represents the contribution assigned to relational information

A nonlinear formulation may also be investigated where relational structure changes the effective behaviour of the system rather than simply adding an independent quantity.

11. Predictive Improvement

The framework proposes comparing two predictive models.

Transactional model

PT = P(Xt+1 | Xt)

Relational model

PR = P(Xt+1 | Xt, Rt, Mt, Ct)

The predictive difference can then be represented as:

ΔP = PR − PT

The empirical task is to determine whether the additional relational variables produce measurable predictive improvement under controlled conditions.

12. Experimental Design

A basic experiment can contain two model classes:

  • Baseline transactional model
  • Relationally enriched model

Both models should receive comparable training data and evaluation conditions.

The relational model additionally receives variables representing relationships, memory and context.

Performance can then be compared using an appropriate predictive metric.

13. Information-Theoretic Evaluation

The experiment can estimate:

I(Xt+1; Rt | Xt)

and, where appropriate:

I(Xt+1; Rt, Mt, Ct | Xt)

The estimates should be accompanied by uncertainty analysis, suitable controls and statistical validation.

14. Temporal Structure

Relational intelligence is not necessarily instantaneous. Relationships can accumulate and change over time.

Rt+1 = G(Rt, Xt, Ct)

Memory may similarly evolve:

Mt+1 = H(Mt, Xt, Rt)

The resulting system is therefore dynamic rather than static.

15. Relation to Resonance Transformation Theory

The information-theoretic framework provides a potential measurement layer for Resonance Transformation Theory.

RTT proposes a resonance coefficient:

ρ(t) = Alignment(Xt, Rt, Ct)

The proposed transformation model is:

Xt+1 = Xt + αρtRt + βCt + εt

The information-theoretic programme provides a possible route for testing whether the relational and contextual components represented in RTT contain measurable predictive information.

16. From Information to Transformation

The proposed architecture can therefore be represented as:

Context → Relationship → Information → Resonance → Transformation → Memory → Future Context

Within this architecture, information is not treated solely as a static resource. It becomes part of a dynamic feedback process through which the system updates its future state.

17. Living Intelligence

The broader Living Intelligence framework represents intelligence as an emergent property of interacting entities and relationships.

Isystem = Σ Ii + Irelations + Iemergence

The information-theoretic programme provides a potential method for investigating whether the relational and emergent terms contribute measurable information beyond isolated component states.

18. Research Questions

  • Does relational structure contain predictive information about future system states?
  • Does memory increase the predictive value of relational information?
  • Does contextual information alter the relationship between present and future states?
  • Can relationally enriched models outperform transaction-only baselines?
  • Can information-theoretic measurements help operationalise relational intelligence?
  • Can resonance be connected to measurable changes in system dynamics?

19. Proposed Research Programme

The investigation can proceed through progressively more complex systems:

  1. Synthetic systems with known relational structures
  2. Network simulations
  3. Multi-agent environments
  4. Biological or ecological systems where appropriate
  5. Human learning and interaction environments
  6. Physical experimental platforms such as the Anuma Learning Station

20. Scientific Positioning

Established science
Mutual information, conditional mutual information, entropy, probability theory and statistical dependence are established mathematical and information-theoretic concepts.

Proposed framework
The interpretation of relational information as a component of “relational intelligence” is proposed within this research programme.

Testable hypotheses
The predictive contribution of relationships, memory, context and resonance can be investigated empirically.

21. Open Problems

  • How should relational structure be represented across different domains?
  • How should relational intelligence be operationally measured?
  • How can causal influence be distinguished from statistical dependence?
  • How should changing network topology affect information measurements?
  • How should resonance be mathematically defined for different physical and social systems?
  • What experimental conditions are sufficient to demonstrate genuine relational emergence?

22. Conclusion

The information-theoretic formulation establishes a mathematical bridge between the conceptual distinction of transactional and relational intelligence and an experimentally testable research programme.

Its central proposed test is:

I(Xt+1; Rt | Xt) > 0

The expression does not by itself establish a new law of intelligence. Rather, it defines a measurable question: whether relational structure contains predictive information about future states beyond the present state.

This question provides a formal connection between information theory, network science, dynamical systems, relational intelligence and the broader Anuma research programme.
